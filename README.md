# 📝 Manage Tasks App
The Manage Tasks App is a Task Management System built using Payload CMS (Postgres) and Next.js. It is designed to help users manage their daily tasks efficiently and easily.

✨ Features
Task Management: Full Create, Read, Update, and Delete (CRUD) capabilities for tasks.

Analytics Dashboard: Visualize task statuses and progress using interactive charts.

Responsive Design: Optimized for a seamless experience across Mobile, Tablet, and Desktop devices.

Dark Mode: Easily toggle between Dark and Light themes.

Postgres Integration: Robust data storage powered by Neon.tech.

🛠️ Tech Stack
Framework: Next.js 15

CMS: Payload CMS (Postgres Adapter)

Database: Neon (PostgreSQL)

Styling: Tailwind CSS + Shadcn UI

Deployment: Vercel

🚀 Getting Started
Run pnpm install to install dependencies.

Add your DATABASE_URI and PAYLOAD_SECRET to the .env file.

Run pnpm dev to start the development server.
